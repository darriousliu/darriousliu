## 🚀 Featured Projects

### 🖼️ [PiPixiv](https://github.com/darriousliu/PiPixiv)

[![GitHub Stars](https://img.shields.io/github/stars/darriousliu/PiPixiv?style=flat-square&logo=github)](https://github.com/darriousliu/PiPixiv)
[![GitHub Downloads](https://img.shields.io/github/downloads/darriousliu/PiPixiv/total?style=flat-square&logo=github)](https://github.com/darriousliu/PiPixiv/releases)

A third-party Pixiv client built with **Kotlin Multiplatform + Compose Multiplatform** for Android, iOS, Windows, macOS, and Linux.

Browse and download illustrations, read novels, and translate them with AI. Features include saved reading progress, translation caching, and task queues, with shared UI and business logic across mobile and desktop.

👉 [Source & Features](https://github.com/darriousliu/PiPixiv) · [Downloads](https://github.com/darriousliu/PiPixiv/releases)

### 📐 [RaTeX-CMP](https://github.com/darriousliu/RaTeX-CMP)

[![GitHub Stars](https://img.shields.io/github/stars/darriousliu/RaTeX-CMP?style=flat-square&logo=github)](https://github.com/darriousliu/RaTeX-CMP)

A LaTeX math rendering library for **Compose Multiplatform**, powered by [RaTeX](https://github.com/erweixin/RaTeX).

Provides a unified Compose API for displaying math on Android, iOS, JVM Desktop, and Web JS / Wasm, with the required rendering dependencies integrated for each platform.

👉 [Source & Integration Guide](https://github.com/darriousliu/RaTeX-CMP)

### 💾 [mmkv-kotlin](https://github.com/darriousliu/mmkv-kotlin)

[![GitHub Stars](https://img.shields.io/github/stars/darriousliu/mmkv-kotlin?style=flat-square&logo=github)](https://github.com/darriousliu/mmkv-kotlin)

A Kotlin Multiplatform key-value storage library extending [ctripcorp/mmkv-kotlin](https://github.com/ctripcorp/mmkv-kotlin).

Adds JVM Desktop support, including native library integration and distribution for Windows, macOS, and Linux, so KMP apps can use MMKV on desktop.

👉 [Source & Integration Guide](https://github.com/darriousliu/mmkv-kotlin)

## 📦 Other Projects

### [commonmark-kotlin](https://github.com/darriousliu/commonmark-kotlin)

A Kotlin Multiplatform Markdown parsing and rendering library adapted from [commonmark-java](https://github.com/commonmark/commonmark-java). Supports Android, iOS, and JVM, with extensions for tables, task lists, footnotes, LaTeX, and more.

### [KotlinTeX](https://github.com/darriousliu/KotlinTeX) · Archived

An earlier Kotlin Multiplatform LaTeX rendering library, adapted from AndroidMath with FreeType integration. No longer maintained; see [RaTeX-CMP](https://github.com/darriousliu/RaTeX-CMP) for new projects.
